    MathML

    E = m c 2

    MathML has been part of the HTML standard for years, but browser support was uneven. Firefox has supported it since version 2 and Safari since version 10, while Chrome added it in version 24 and then removed it because it was unstable. Chrome and Edge only shipped MathML again in version 109, in January 2023, so until then most sites used images or libraries like MathJax instead.
